# ADR-0001: LOCALE_ENUM 采用国家码键 + M.49 分组 + 单代表语言（248 项穷尽）

`I18nUtil.LOCALE_ENUM` 以 ISO 3166-1 alpha-2 国家/地区代码为键、覆盖除南极洲（AQ，无常驻人口及官方语言）外的全部 248 项，值为该国代表语言的完整 Locale，注释按联合国 M.49 地理区域分组展示。

选择国家码键而非语言名键（早期版本为 28 项语言名枚举）：国家/地区是「语言 → Locale」语义的自然载体，且穷尽可枚举（ISO 3166-1 全集），杜绝「该收录哪种语言」的主观裁量；语言级枚举另以 `PRIMARY_LANGUAGE_ENUM`（74 个语言子标签 → 代表地区完整 Locale）承担，并作为 `toFullLocale` 运行时查找与类型派生的单一数据源（`LOCALE_ENUM` 的全部值须落在其中，测试断言）。两个枚举均为 `I18nUtil` 公开静态成员。

代表语言选择规则（人工维护，非机械规则）：人口最多语言优先；无主导语言的属地/前殖民地默认英语；个别按 CLDR 默认内容语言调整（如新加坡 → 英语、卢旺达 → 基尼亚卢旺达语）。

Status: accepted
